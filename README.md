# lucastexr.com

A design canvas with eleven artboards for the portfolio site of Lucas Teixeira: home, work, a case study, writing, an essay, photography, about, contact and two phone screens.

Live: https://oliveira-teixeira.github.io/design-lucastexr-com/

## Stack

- Plain HTML and CSS with inline styles, no JavaScript in the artboards
- Google Fonts: Inter
- Lucide icons inlined as SVG paths
- Project images in `boards/assets/`
- Canvas viewer in `index.html`: plain HTML and CSS with a few lines of JavaScript that scale each artboard to fit the window
- Originally a Design canvas on claude.ai. Each artboard was flattened into a standalone static page in `boards/`, so nothing depends on the claude.ai runtime

Exported from a claude.ai artifact on 9 Oct 2026.
